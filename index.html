QUICK REFERENCENOTEBOOK / A

System notes

Small reminders for the next time a problem shows up.

ipconfigCheck network settings +

On Windows, displays IP configuration such as addresses, gateways, and DNS information. Other systems use different commands, such as ip addr on Linux.

pingTest reachability +

Sends test packets to check whether a destination responds. A failed ping alone does not prove a host is offline; firewalls and network policy may block it.

whoamiConfirm the current account +

Shows the current user identity in many command-line environments. Exact availability and output vary by operating system and shell.

Read the output before changing anything.

06 ACADEMIC REQUIREMENT / CAREER PATHWAY

From first response to resilient systems.

A common progression has multiple routes. Each level below describes typical work and skills to develop, not a promise of promotion.

LEVEL 01

IT Support / Help Desk

Entry level · User-facing support

Provides a first point of contact for everyday hardware, software, account, and connectivity problems.

RESPONSIBILITIES
  • Respond to support requests and clarify symptoms.
  • Set up devices and assist with basic account access.
  • Document fixes and escalate issues when needed.
SKILLS TO DEVELOP

Customer service · OS basics · Troubleshooting · Ticket documentation

LEVEL 02

Junior System Administrator

Developing · System operations

Helps maintain the servers, user accounts, and shared services a team relies on.

RESPONSIBILITIES
  • Manage users, groups, permissions, and routine updates.
  • Check system health, logs, and scheduled backups.
  • Investigate incidents and record configuration changes.
SKILLS TO DEVELOP

Linux / Windows · Networking · Access control · Backup fundamentals

LEVEL 03

Senior SysAdmin / Systems Engineer

Advanced · Design & reliability

Designs and improves infrastructure with attention to reliability, security, and scale.

RESPONSIBILITIES
  • Plan and improve server or cloud infrastructure.
  • Automate repeatable operational tasks and recovery plans.
  • Lead complex incident response and share technical guidance.
SKILLS TO DEVELOP

Automation · Architecture · Resilience · Risk management

Illustrative career levels only: role scope and prerequisites vary between organizations.
