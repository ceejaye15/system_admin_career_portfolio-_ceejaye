# SysPath — The System Admin Lab Journal

A responsive personal system administration learning portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Project files

- `index.html` — journal layout, required academic sections, learning entries, simulator, and editable creator profile.
- `style.css` — warm editorial theme, responsive layouts, interaction states, and reduced-motion support.
- `script.js` — mobile navigation, active section links, three simulated troubleshooting cases, and current year.

## Run and preview locally

1. Open the project folder in VS Code.
2. Open `index.html` directly in a modern browser, or use VS Code's Live Server extension.
3. Alternatively, open a terminal in this folder and run `python -m http.server 8000`, then visit `http://localhost:8000`.

No database, login system, package installation, build step, or additional dependency is needed. The Google Fonts link is optional; system fallback fonts are provided if the network is unavailable.

## Personalize before publishing

Review the profile details in the **About the Creator** section of `index.html` and update any details that have changed. Add only real projects or contact information you want to share. No work history, certifications, or completed achievements are claimed.

## Academic requirement checklist

- **Home:** project title, introduction to system administration careers, and working navigation.
- **System Administrator Career Pathway:** three connected, visually distinct level cards from IT Support / Help Desk through Junior System Administrator to Senior SysAdmin / Systems Engineer; every level has a job title, description, responsibilities, and skills to develop.
- **Skills and Qualifications:** six relevant skill areas with brief explanations of their role in system administration, plus future qualification ideas.
- **Job Roles and Responsibilities:** Career Direction describes four related roles, their typical responsibilities, and relevant skills.
- **Required Skills and Tools:** six relevant skills plus explanations of Linux, Windows, PowerShell, Bash, virtual machines, and Wireshark.
- **About the Developer:** name, BSIT program, personal introduction, preferred career path, and professional goal.
- **Additional journal feature:** six expandable lab entries, a five-stage learning map, and three interactive, simulated troubleshooting scenarios.

## Before submission

- Update the About fields with real details you want to share.
- Exercise each troubleshooting scenario, expandable journal entry, and system note.
- Check the menu at a narrow viewport and follow every navigation link.
- Capture your own desktop and mobile screenshots and submit the approved local demo or website URL together with all three source files.
